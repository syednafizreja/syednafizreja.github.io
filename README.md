# syednafizreja.github.io

Personal site of Syed Nafiz Reja Hasib: computational design and mechanics of structures, with concrete shells as the current test case.

Live: https://syednafizreja.github.io

- Built with [Astro](https://astro.build); deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.
- Edit content through [Pages CMS](https://app.pagescms.org) or the files in `src/content/` and `src/data/site.json`. See [docs/EDITING.md](docs/EDITING.md).
- Decisions and open items: [SITE_LOG.md](SITE_LOG.md). Licences: [CREDITS.md](CREDITS.md).

```sh
npm ci
npm run dev        # local preview
npm run build      # static output in dist/
npm run test:e2e   # accessibility and behaviour tests
```
